Initial working ChirpStack Docker baseline.

Tested environment:

- Windows 11
- WSL2 Ubuntu
- Docker Desktop
- ChirpStack Web UI available at http://localhost:8080

Included services:

- ChirpStack
- PostgreSQL
- Redis
- Mosquitto MQTT
- ChirpStack Gateway Bridge
